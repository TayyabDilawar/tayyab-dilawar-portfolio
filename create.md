# Build an Advanced Professional MERN Stack Developer Portfolio

You are an expert Senior Frontend Engineer, UI/UX Designer, Next.js Architect, SEO specialist, and performance engineer.

I am a professional **MERN Stack Developer** and I want to build a premium, modern, highly interactive personal portfolio website that represents me as an experienced full-stack developer.

Build the complete portfolio from scratch using the latest stable version of **Next.js 16** with the App Router.

Do NOT build a generic portfolio template. The website should look like a high-end developer portfolio that could represent a senior freelance/full-stack developer.

# 1. Core Technology Stack

Use:

* Next.js 16 latest stable
* React latest compatible version
* TypeScript
* App Router
* Tailwind CSS latest
* shadcn/ui
* Lucide React icons
* Framer Motion / Motion for animations
* next/image
* next/font
* ESLint
* Prettier if useful

Use modern Next.js architecture and best practices.

Use Client Components ONLY where interactivity is required.

Use Server Actions where appropriate.

Use clean reusable components.

Use TypeScript strictly.

Avoid `any` unless absolutely unavoidable.
